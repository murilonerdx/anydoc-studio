    Configurações de tradução

    A tradução usa uma IA que você controla. Opção local recomendada (Ollama) — nada sai da sua máquina. A chave de API é opcional e fica salva só no seu navegador.

    Melhores para documentos: translategemma (tradução dedicada), aya:8b (100+ idiomas), qwen2.5:7b (técnico). Instale com ollama pull <modelo>.
    Precisa do Ollama rodando e permitir esta origem: OLLAMA_ORIGINS=http://127.0.0.1:8777 ollama serve

    Tradução neural 100% no navegador (tecnologia do Firefox). Sem servidor, sem chave — os modelos do idioma baixam uma vez (alguns MB) e ficam em cache. Cobre os principais idiomas europeus (pivô via inglês).

    Servidor open-source auto-hospedado (Argos). Ex.: docker run -p 5000:5000 libretranslate/libretranslate

    Rode python proxy.py 8788 e cole a URL aqui para raspar qualquer site — local, sem serviço externo.
